# Documentos PNCP

Pasta de destino dos prints e dos arquivos oficiais (edital, ata de registro de preços, contrato) de cada referência de preço.

Os portais PNCP e Compras.gov.br exigem verificação hCaptcha, por isso a captura é feita no navegador do servidor, com o script `../captura_evidencias_pncp.py`. As instruções estão no cabeçalho do script.

Enquanto a captura não for feita, a evidência de cada preço é a ficha em `../Fichas/` e o print em `../Prints/`, gerados a partir da API oficial de Dados Abertos do Compras.gov.br.
